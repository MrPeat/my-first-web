# 👋 สวัสดีGitHub
## ข้อมูลของฉัน
- ชื่อ-สกุล : นาย ภานุวัฒน์ ขันทกะพันธ์
- ชื่อเล่น : เพชร
- สาขาวิชา : วิทยาการคอมพิวเตอร์แบะสารสนเทศเอก ดิจิทัล
## เป้าหมายในการเรียนรายวิชานี้
เขียนโปรแกรมเป็นและสามารถเข้าใจในทุกส่วนที่เป็นคนทำ สามารถเข้าใจทุกส่วนของการทำเว็ปและแอปพลิเคชั่นทุกส่วนแต่ยากมากครับไม่เข้าใจสักส่วนเลยตอนนี้

## สิ่งที่ฉันสนใจ
ตอนนี้สิ่งที่สนใจคือการใช้ Ai ครับแล้วก็ web mobile ครับ

## ความคาดหวังจากการเรียนวิชานี้
1.ทำเว็ปและแอปเป็นคนเดียวและเข้าใจทุกส่วนที่ทำ
2. เรียนได้และเรียนเข้าใจ
3.  อาจารย์ไม่ดุครับเพราะผมเรียนไม่ค่อยเข้าใจเท่าไหร่เพราะไม่ค่อยรู้เรื่องครับ
